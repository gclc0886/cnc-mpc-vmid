# CNC Kinematic Simulator / Trainer

Визуально-математический симулятор кинематики многоосевых станков с ЧПУ с интеграцией MCP (Model Context Protocol) для управления через ИИ-агента.

## Что это?

CNC Trainer позволяет строить, визуализировать и симулировать кинематику станков с ЧПУ — от простых 3-осевых фрезерных до сложных многоревольверных токарно-фрезерных центров. Приложение подключается к **Claude Code** через протокол MCP, предоставляя ИИ-агенту полный контроль над симулятором: загрузка станков, перемещение осей, выполнение G-code, чтение матриц трансформации и многое другое.

### Основные возможности

- **Кинематический движок** — матрицы трансформации 4x4, две цепи (инструмент + заготовка), расчёт TCP в MCS/WCS
- **3D-визуализация** — интерактивный Three.js вьюпорт с моделью станка, протракторы (лимбы) на поворотных осях, отрисовка траектории
- **Симуляция G-code** — Sinumerik-совместимый парсер (G0/G1/G2/G3, дуги IJK/R/CR=, плоскости G17-G19, G90/G91)
- **Формат VMID** — полный импорт/экспорт файлов SolidCAM Virtual Machine ID (Ver 24–58), включая суб-машины, каналы и access patterns
- **MCP-интеграция** — 21 инструмент для инспекции, конфигурации и симуляции станка через ИИ
- **Маппинг осей суб-машин** — поддержка Mill-Turn с множественными комбинациями турель/стол и маппингом координат G-code
- **5 встроенных пресетов** — 3-осевой, 4-осевой, 5-осевой Table-Table, 5-осевой Head-Head, токарно-фрезерный

## Архитектура

```
Claude Code  <-->  MCP Server (stdio, Node.js)
                       |
                  WebSocket :3100
                       |
                  Electron / Browser (React)
                       |
                  Zustand Store <-> KinematicChain Engine
```

| Слой | Файл | Роль |
|------|------|------|
| MCP-сервер | `mcp-server/cnc-trainer-mcp.ts` | 21 инструмент, WebSocket relay |
| Bridge-клиент | `src/api/BridgeClient.ts` | WS-клиент на стороне браузера |
| Хранилище | `src/store/useMachineStore.ts` | Центральное состояние (Zustand) |
| Кинематический движок | `src/engine/KinematicChain.ts` | Прямая кинематика, матричная математика |
| Парсер G-code | `src/engine/GCodeParser.ts` | G0/G1/G2/G3, дуги IJK/R/CR= |
| Загрузчик VMID | `src/engine/VMIDLoader.ts` | Импорт/экспорт SolidCAM VMID |
| 3D-рендерер | `src/visualization/MachineModel.tsx` | Модель станка Three.js |

## Быстрый старт

### Требования

- Node.js 18+
- npm

### Установка и запуск

```bash
# Клонирование
git clone https://github.com/gclc0886/cnc-mpc-vmid.git
cd cnc-mpc-vmid

# Установка зависимостей
npm install

# Запуск в браузере
npm run dev
# Откройте http://localhost:5173

# Запуск как Electron-приложение
npm start
```

### Подключение к Claude Code

Добавьте в ваш `~/.claude.json`:

```json
{
  "mcpServers": {
    "cnc-trainer": {
      "command": "npx",
      "args": ["tsx", "mcp-server/cnc-trainer-mcp.ts"],
      "cwd": "/путь/к/cnc-mpc-vmid"
    }
  }
}
```

Сначала запустите приложение (Electron или браузер), дождитесь зелёного индикатора подключения в тулбаре, затем используйте MCP-инструменты из Claude Code.

## MCP-инструменты (21 шт.)

### Чтение состояния
| Инструмент | Возвращает |
|------------|-----------|
| `get_machine_state` | Полное состояние: имя, тип, позиции всех осей, TCP, статус воспроизведения |
| `get_axis_positions` | Текущие значения осей (мм / градусы) |
| `get_tool_position` | TCP в координатах MCS и WCS |
| `get_matrices` | Все матрицы трансформации 4x4 |
| `get_config` | Полный KinematicConfig в JSON |
| `get_animation_state` | Текущий шаг, всего шагов, статус воспроизведения |

### Управление станком
| Инструмент | Действие |
|------------|---------|
| `load_preset` | Загрузить пресет (3x, 4x, 5x_ac, 5x_bc, turn_mill) |
| `load_vmid` | Загрузить станок из VMID XML |
| `set_axis_value` | Переместить одну ось |
| `set_axes` | Переместить несколько осей одновременно |
| `reset_axes` | Обнулить все оси |

### G-code и анимация
| Инструмент | Действие |
|------------|---------|
| `load_gcode` | Загрузить G-code в редактор |
| `parse_gcode` | Распарсить и сгенерировать траекторию |
| `play_animation` | Запустить воспроизведение |
| `pause_animation` | Поставить на паузу |
| `set_animation_step` | Перейти к шагу |

### Конфигурация
| Инструмент | Действие |
|------------|---------|
| `update_axis_config` | Изменить свойства оси |
| `add_axis` | Добавить ось в дерево устройства |
| `add_device` | Добавить устройство (шпиндель/стол) |
| `remove_axis` | Удалить ось |

## Модель данных

### Конфигурация станка

Станок состоит из **устройств** (spindle = цепь инструмента, table = цепь заготовки), каждое из которых содержит дерево **осей** (linear, rotary, static). Кинематический движок вычисляет прямую кинематику, обходя каждую цепь и перемножая матрицы трансформации 4x4.

### Суб-машины (Combinations)

Для токарно-фрезерных станков **комбинация** определяет связку турель + стол с **порядком осей**, который маппит координаты G-code на физические оси:

```
axesOrder.linear[0] → G-code X
axesOrder.linear[1] → G-code Y
axesOrder.linear[2] → G-code Z
axesOrder.rotary[0] → G-code A
axesOrder.rotary[1] → G-code B
axesOrder.rotary[2] → G-code C
```

### Каналы и Access Patterns

- **Каналы (Channels)** — независимые группы осей со своими суб-машинами (для координации нескольких турелей)
- **Access Patterns** — режимы обмена осями между каналами (`normal` / `forbidden` / `exchange`), используются для Swiss-type станков (G140/G142)

## Поддержка формата VMID

VMID (Virtual Machine ID) — формат описания станка SolidCAM. CNC Trainer обеспечивает полный round-trip:

- **Импорт**: Ver 24 (SubDevices) и Ver 30+ (Components)
- **Экспорт**: Ver 58 с полной иерархией
- **Разбираемые элементы**: SubDevices с координатными системами, деревья осей, комбинации с порядком осей, каналы, access patterns
- **Round-trip**: Загрузка → Редактирование → Сохранение без потери данных

## Скриншоты

*Запустите приложение и загрузите пресет или VMID-файл, чтобы увидеть 3D-модель станка с интерактивными ползунками осей, лимбами на поворотных осях и визуализацией траектории.*

## Применение

- **Изучение кинематики ЧПУ** — визуализация того, как оси компонуются для позиционирования инструмента
- **Отладка VMID-файлов** — загрузка, инспекция и редактирование описаний станков SolidCAM
- **Верификация G-code** — симуляция траекторий и проверка перемещений осей
- **Построение станков с помощью ИИ** — Claude Code конфигурирует станки через MCP
- **Разработка постпроцессоров** — проверка маппинга осей и координатных трансформаций
- **Настройка Mill-Turn** — тестирование конфигураций суб-машин и режимов обмена осями
