## Context

CNC Trainer (`C:\CLAUDE-MCP\CNC-Trainer`) — Electron + React 19 + R3F + Zustand симулятор кинематики станков с ЧПУ с MCP-мостом. ~4000 строк в `src/`, тестов нет, `npx tsc --noEmit` сейчас чистый. Владелец — CAM-инженер (SolidCAM, VMID, Sinumerik 828D/840D), общается по-русски, тестирует **только в Electron**.

Цель апгрейда — два равноправных сценария:
1. **Проверка постпроцессора**: загрузить реальный VMID + G-код из SolidCAM и достоверно увидеть, как поедет станок (индексация, wrapping, знаки, лимиты).
2. **Обучение кинематике**: наглядные матрицы, цепи, RTCP, преобразования.

Сейчас оба сценария упираются в одно: G-код XYZABC напрямую пишется в оси станка (`applyStep`), без модальных групп, смещений, длины инструмента и преобразований, а часть математики и VMID-разбора неверна. Пользователь выбрал все четыре направления: G-код Sinumerik, Mill-Turn/Swiss, визуализация, MCP/инфраструктура.

**Шаг передачи:** план лежит в `docs/UPGRADE_PLAN.md`; работа идёт по фазам прямо в `main`.

## Целевая архитектура (ключевое решение)

Разделить «что запрограммировано» и «куда едут оси». Новый конвейер в `src/engine/`:

```
текст → Lexer → Block[] → Interpreter (модальное состояние, фреймы, циклы)
      → ProgramMove[] (WCS, кончик инструмента)
      → MachineMapper (G54 + длина инструмента + трансформация + активная суб-машина)
      → MachineSample[] (значения физических осей + время)
```

```ts
interface ProgramMove { blockIndex; channelId; kind:'rapid'|'linear'|'arc'|'dwell';
  target:{x,y,z}; rot:{a?,b?,c?}; arc?:{center,plane,cw}; feed; feedMode:'G94'|'G95';
  frame: Matrix4x4;            // активный фрейм: G54 ∘ TRANS/ROT ∘ CYCLE800
  trafo:'none'|'traori'|'transmit'|'tracyl'; tool:{T,D,length,radius} }

interface MachineSample { t:number;          // сек от старта программы
  axes: Float64Array;                        // по индексу оси цепи (не по имени)
  tcpWcs:[number,number,number]; blockIndex:number; rapid:boolean; feed:number;
  flags:number }                             // LIMIT | SINGULARITY | UNSUPPORTED
```

`SimPoint` и `applyStep` заменяются на `MachineSample` и `chain.setAxisValues(Float64Array)` (один пересчёт матриц). Старые поля стора `toolPath/currentStep` сохраняют смысл (массив сэмплов / индекс), чтобы MCP-контракт не ломался.

**1a. Ядро (закрывает B2–B6):**
- Lexer: диалект `sinumerik` (по умолчанию; комментарий только `;`) / `fanuc` (`(...)`); слова `X10`, `X=expr`, `CR=`, `AC()/IC()/DC()/ACP()/ACN()`, `N`-номера, метки, имена подпрограмм/циклов с аргументами.
- Модальные группы: движение G0/1/2/3, плоскость G17/18/19, G90/G91, G94/G95, G53/G500/G54–G57/G505+, DIAMON/DIAMOF, T/D, S/M3/M4/M5. Несколько G и M в одном блоке.
- Дуги во всех плоскостях: IJK, `CR=`, `R` (fanuc), спираль, полный круг — переиспользовать математику `_interpolateArc` (`GCodeParser.ts:331-390`), убрав угадывание плоскости.
- Дискретизация по линейному **и** угловому шагу (1 мм / 1°); чисто поворотные ходы — по времени в °/мин.
- Время: `t` по подаче (G94), rapid — по `Rapid` оси из VMID (сейчас не читается, добавить в `AxisDef`).
- Диагностика: `Diagnostic{line, severity, message}` для неподдержанных слов — ничего не глотать молча.

**1b. Смещения и фреймы:** таблица G54–G57 и таблица инструментов (T/D → длина, радиус) в сторе с UI-редактором; `TRANS/ATRANS`, `ROT/AROT` (+ `SCALE/MIRROR` по остаточному принципу). Без трансформации: ось = программная координата ∘ фрейм + компенсация длины по оси инструмента.

**1c. Кинематические трансформации:**
- `TRAORI/TRAFOOF` (RTCP): при заданных углах поворотных осей FK линейна по линейным осям → `tip = f(rot) + J(rot)·lin`; J и f получаются 4 вызовами FK, решается система 3×3. Работает для любой цепи с 3 линейными осями, без частных формул под тип станка. Вырожденный J → флаг `SINGULARITY`.
- `TRANSMIT`: `X = hypot(x,y)`, `C = atan2(y,x)` с развёрткой непрерывности.
- `TRACYL(d)`: поворотная = `y / (π·d) · 360`.
- `CYCLE800` (поворот плоскости для 3+2 / 4-осевой индексации): углы → позиции поворотных осей + фрейм.

**1d. Циклы:** `CYCLE81/82/83/84`, `MCALL`, `HOLES1/2` → разворачиваются в `ProgramMove`. Сверять порядок аргументов с `skills/sinumerik-macro/SKILL.md` и `skills/solidcam-postprocessor/SKILL.md`.

**1e. (в конце плана) Параметрика:** R-параметры, `DEF`, выражения, `IF/GOTOF/GOTOB`, `FOR/WHILE/REPEAT` с лимитом итераций, вызов SPF из соседних файлов.
