================================================================================
                    CNC KINEMATIC SIMULATOR / TRAINER
                         Описание приложения
================================================================================

1. НАЗНАЧЕНИЕ
--------------------------------------------------------------------------------
CNC Trainer — визуально-математический симулятор кинематики многоосевых
станков с ЧПУ. Приложение позволяет:

  - Визуализировать кинематические цепи станков (от 3 до 5+ осей)
  - Загружать и редактировать конфигурации из VMID-файлов (формат SolidCAM)
  - Воспроизводить G-code программы с анимацией движения осей
  - Рассчитывать и отображать матрицы трансформации (4x4) в реальном времени
  - Конфигурировать параметры осей: векторы, лимиты, офсеты, центры вращения
  - Сохранять измененные конфигурации обратно в формат VMID (Ver 58)
  - Поддерживать Mill-Turn станки с множественными суб-машинами и каналами


2. ТЕХНИЧЕСКИЙ СТЕК
--------------------------------------------------------------------------------
  Frontend:      React 19 + TypeScript + Vite 8
  3D-рендеринг:  Three.js (через @react-three/fiber + @react-three/drei)
  Состояние:     Zustand 5
  Desktop:       Electron 41
  MCP-интеграция: @modelcontextprotocol/sdk + WebSocket мост (порт 3100)


3. СТРУКТУРА ИНТЕРФЕЙСА
--------------------------------------------------------------------------------
  Левая часть:     3D-вьюпорт с моделью станка, индикаторы MCS/WCS координат,
                   углы поворотных осей и угловые скорости при симуляции
  Правая панель:   Вкладки Controls / Configure
    - Controls:    Ползунки осей (с кнопками шага +/-1), блок Playback, матрицы
    - Configure:   Редактор параметров осей (вектор, лимиты, тип, центр вращения)
  Нижняя панель:   Редактор G-code с индикацией текущей строки
  Все панели:      Масштабируемые перетаскиванием разделителей

  Панель инструментов: пресеты станков, загрузка/сохранение VMID, сброс

  Блок Playback:
    - Выбор суб-машины (комбинации) — dropdown при наличии 2+ комбинаций
    - Play/Pause/Stop, Step ±1, Jump ±20
    - Скорость воспроизведения (0.5x–10x)
    - Скруббер (ползунок прогресса)
    - Индикация: шаг/всего, строка G-code, G0 Rapid / F подача
    - Углы поворотных осей и угловая скорость (°/мин)


4. ВСТРОЕННЫЕ ПРЕСЕТЫ СТАНКОВ
--------------------------------------------------------------------------------
  - 3-Axis Mill        (X, Y, Z)
  - 4-Axis Mill        (X, Y, Z, A)
  - 5-Axis Trunnion    (X, Y, Z, A, C) — Table-Table
  - 5-Axis Head-Head   (X, Y, Z, B, C) — Head-Head
  - Turn-Mill          (X, Z, Y, C)     — токарно-фрезерный


5. КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ
--------------------------------------------------------------------------------
  a) Кинематическая цепь:
     - Прямая кинематика (Forward Kinematics) с матрицами трансформации
     - Две цепи: шпиндель (Tool → World) и стол (Workpiece → World)
     - Относительная матрица: Inv(Workpiece) × Tool
     - Вычисление TCP (Tool Center Point) в MCS и WCS
     - Категории станков: mill_3x, mill_4x, mill_5x, mill_5x_headhead, turn_mill

  b) G-code движок:
     - Парсер Siemens Sinumerik-совместимого G-code
     - Поддержка: G0, G1, G2/G3 (IJK, R, CR= форматы дуг), G17/G18/G19,
       G90/G91, G54
     - Интерполяция траектории с заданным шагом (1 мм по умолчанию)
     - SimPoint: x/y/z/a/b/c + feed + rapid + blockIndex

  c) 3D-визуализация:
     - Модель станка из кинематической конфигурации (рекурсивное дерево узлов)
     - Полупрозрачный протрактор (транспортир) на поворотных осях
       с градусными делениями, радиальными метками (шрифт 50px)
     - Инструмент с TCP, системой координат и корпусом шпинделя
     - Визуализация траектории инструмента (rapid=красный, feed=зелёный градиент)

  d) VMID формат (SolidCAM Virtual Machine ID):
     - Импорт: Ver 24 (SubDevices) и Ver 30+ (Components) форматов
     - Экспорт: Ver 58 с вложенной иерархией осей, Device, PostProcessor
     - Парсинг суб-машин (Combinations) с порядком осей (axesOrder)
     - Парсинг каналов (Channels) с привязкой суб-машин
     - Парсинг access patterns (режимы обмена осями G140/G142)
     - Координатные системы устройств (VecX/VecY/VecZ/Place)
     - Полный round-trip: загрузка → редактирование → сохранение без потери данных

  e) Конфигуратор:
     - Древовидная структура осей по устройствам (шпиндель, стол)
     - Редактирование: имя, тип (linear/rotary/static), вектор, лимиты, центр
     - Добавление и удаление осей
     - Добавление устройств (spindle/table)
     - Сохранение состояния при редактировании (preserveState)

  f) Суб-машины и маппинг осей (Axis Mapping):
     - Комбинация = связка турели + стола с порядком осей
     - axesOrder.linear[0..2] → G-code X, Y, Z
     - axesOrder.rotary[0..2] → G-code A, B, C
     - ID осей → имена осей через buildAxisIdMap()
     - Автовыбор первой комбинации при загрузке станка
     - Fallback на прямой маппинг (X→X) если комбинация отсутствует
     - UI-dropdown для выбора активной суб-машины


6. МОДЕЛЬ ДАННЫХ
================================================================================

  KinematicConfig (полная конфигурация станка):
  ─────────────────────────────────────────────
  name            Имя станка
  type            'milling' | 'turn_mill'
  kinematic       'No-Rotary' | 'Table-Table' | 'Head-Head' | 'Turn-Mill'
  axisCount       Количество осей (без static)
  linearAxes      Имена линейных осей ['X', 'Y', 'Z']
  rotaryAxes      Имена поворотных осей ['A', 'C']
  devices         Устройства (DeviceDef[])
  combinations    Суб-машины (CombinationDef[])
  channels        Каналы (ChannelDef[])
  accessPatterns  Режимы обмена осями (AccessPatternDef[])
  postprocessor   Имя постпроцессора

  DeviceDef (устройство):
  ───────────────────────
  id              Уникальный ID
  name            Имя ('Spindle', 'Table', 'Turret')
  type            'spindle' (инструмент) | 'table' (заготовка)
  maxSpin         Макс. обороты
  axes            Дерево осей (AxisDef[])
  coordSys        Координатная система {vecX, vecY, vecZ, place} (из VMID)

  AxisDef (ось):
  ──────────────
  name            Имя оси ('X', 'Y', 'Z', 'A', 'B', 'C', ...)
  id              Уникальный ID (для ссылок из axesOrder)
  type            'linear' | 'rotary' | 'static'
  vector          Направление движения/вращения {x, y, z}
  center          Центр вращения {x, y, z} (только rotary)
  offset          Смещение от родителя {x, y, z}
  homeRef         Значение оси при Home
  limits          Пределы хода {min, max}
  children        Дочерние оси (вложенная иерархия)

  CombinationDef (суб-машина):
  ────────────────────────────
  id              Уникальный ID
  name            Имя ('Spindle_Table', 'Turret1_SubSpindle')
  turretId        ID устройства инструмента
  tableId         ID устройства заготовки
  axesOrder       {
                    linear: [axisId_X, axisId_Y, axisId_Z]
                    rotary: [axisId_A, axisId_B, axisId_C]
                  }

  ChannelDef (канал):
  ───────────────────
  id              Уникальный ID
  name            Имя канала
  submachineIds   Ссылки на ID комбинаций
  numLinearAxes   Количество линейных осей
  numRotaryAxes   Количество поворотных осей

  AccessPatternDef (режим обмена осями):
  ──────────────────────────────────────
  id              Уникальный ID
  name            Имя режима
  axisPermissions { [axisId]: 'normal' | 'forbidden' | 'exchange' }


7. ДАННЫЕ ДОСТУПНЫЕ ЧЕРЕЗ MCP (Model Context Protocol)
================================================================================
MCP-сервер (cnc-trainer-mcp) предоставляет Claude Code полный контроль
над симулятором через 21 инструмент, сгруппированных в 5 категорий:

  ГРУППА A — ЧТЕНИЕ СОСТОЯНИЯ (6 инструментов):
  ──────────────────────────────────────────────
  get_machine_state     Полное состояние: имя станка, категория, позиции
                        всех осей, координаты TCP (MCS), фрагмент G-code,
                        текущий шаг анимации, общее число шагов, статус
                        воспроизведения (play/pause)

  get_axis_positions    Текущие значения всех осей в мм (линейные) и
                        градусах (поворотные), например:
                        { "X": 50.0, "Y": 30.0, "Z": -10.0, "A": 45.0 }

  get_matrices          Все матрицы трансформации 4x4:
                        - Матрица каждой оси (в мировых координатах)
                        - Матрица цепи инструмента (Tool → World)
                        - Матрица цепи заготовки (Workpiece → World)
                        - Относительная матрица Inv(Table) × Spindle

  get_tool_position     Позиция TCP (Tool Center Point) в двух системах:
                        - MCS (Machine Coordinate System) — абсолютная
                        - WCS (Work Coordinate System) — относительно заготовки

  get_config            Полная конфигурация KinematicConfig в JSON:
                        имя, тип, кинематика, устройства, иерархия осей
                        с параметрами, комбинации, каналы, access patterns,
                        постпроцессор

  get_animation_state   Состояние анимации: текущий шаг, всего шагов,
                        статус воспроизведения


  ГРУППА B — УПРАВЛЕНИЕ СТАНКОМ (5 инструментов):
  ──────────────────────────────────────────────────
  load_preset           Загрузить пресет: 3x, 4x, 5x_ac, 5x_bc, turn_mill

  load_vmid             Загрузить VMID XML контент в симулятор

  set_axis_value        Установить значение одной оси
                        (имя: X/Y/Z/A/B/C, значение: мм или градусы)

  set_axes              Установить несколько осей одновременно
                        { "X": 100, "Y": 50, "Z": -20, "A": 30 }

  reset_axes            Сбросить все оси в ноль


  ГРУППА C — G-CODE (2 инструмента):
  ──────────────────────────────────────
  load_gcode            Загрузить текст G-code программы в редактор

  parse_gcode           Распарсить текущий G-code и сгенерировать
                        траекторию инструмента (toolpath), вернуть
                        общее количество шагов


  ГРУППА D — АНИМАЦИЯ (4 инструмента):
  ──────────────────────────────────────
  play_animation        Запустить воспроизведение анимации

  pause_animation       Поставить на паузу

  set_animation_step    Перейти к конкретному шагу анимации (по индексу)

  get_animation_state   Получить состояние: текущий шаг, всего шагов,
                        статус воспроизведения


  ГРУППА E — КОНФИГУРАЦИЯ (4 инструмента):
  ──────────────────────────────────────────
  update_axis_config    Изменить свойства оси: тип (linear/rotary/static),
                        вектор направления, офсет, лимиты хода,
                        центр вращения

  add_axis              Добавить новую ось к устройству (шпиндель или стол),
                        с указанием родительской оси для вложенности

  add_device            Добавить новое устройство (spindle/table) с набором осей

  remove_axis           Удалить ось из конфигурации


8. АРХИТЕКТУРА MCP-ИНТЕГРАЦИИ
--------------------------------------------------------------------------------
  Схема взаимодействия:

    Claude Code  ←→  MCP Server (Node.js, stdio)
                          ↕
                    WebSocket (порт 3100)
                          ↕
                    Браузер / Electron (React приложение)
                          ↕
                    Zustand Store ←→ KinematicChain Engine

  - MCP-сервер запускается как отдельный Node.js процесс
  - Использует stdio транспорт для связи с Claude Code
  - Встроенный WebSocket сервер на порту 3100 для связи с браузером
  - Браузерный клиент (BridgeClient) подключается автоматически
  - Зеленый индикатор в toolbar показывает статус подключения
  - Авто-переподключение с экспоненциальной задержкой (1с → 10с макс)
  - Таймаут на ответ от браузера: 5 секунд
  - EADDRINUSE обработка: если порт 3100 занят — сообщение в лог
